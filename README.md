# Radar App Estagio

Monorepo for the Estagio radar project. It includes the mobile app, local stack (backend + dashboard), and supporting scripts.

## Structure
- RadarApp: React Native mobile app
- local-radar-stack: backend, dashboard, docker configs
- Linux: simulator and helper tools
- esp_backups: firmware tooling and backups

## Notes
- Environment files are not committed; use the provided example files where available.
- Generated folders like node_modules and .next are ignored.
